Text network analysis and knowledge graphs via the InfraNodus MCP server: text structure, content gaps, research questions and ideas, text comparison, SEO/GEO and Google search analysis, GraphRAG retrieval, structured memory. Accepts text, URLs (incl. YouTube), and saved graphs. Analyzes and optimizes an LLM's memories (Claude or Codex memory, mem0, claude-mem): optimizes their structure with optimize_knowledge_base and finds gaps to bridge them and enhance the memories. Also graphs a project folder, code repo or Obsidian vault ("graph this repo", "analyze this vault", "/infranodus"): it reads docs, notes, PDFs, code imports and comments, and commit history into saved graphs with a digest and a report, and refreshes them when files change. When infranodus/manifest.json exists in the project root, answer questions about themes, decisions, rationale, or gaps by querying the existing graphs FIRST, before reading files. For an LLM-authored knowledge base built from sources, prefer the llm-wiki skill.
