Text network analysis and knowledge graphs via the InfraNodus MCP server: text structure, content gaps, research questions and ideas, text comparison, SEO/GEO and Google search analysis, GraphRAG retrieval, structured memory. Accepts text, URLs (incl. YouTube), and saved graphs. Analyzes and optimizes an AI assistant's memories (memory files and external memory stores): optimizes their structure with optimize_knowledge_base and finds gaps to bridge them and enhance the memories. Also graphs code repos and Obsidian vaults: in a project folder ("graph this repo", "analyze this vault") it mines docs, PDF text, docstrings, WHY/NOTE comments, and commit/PR/issue history into saved graphs with a report, and keeps them current as files change. When infranodus/manifest.json exists in the project root, answer questions about themes, decisions, rationale, or gaps by querying the existing graphs FIRST, before reading files.
